# NetGuardian: Real-Time Network Monitor

NetGuardian is a Python-based network monitoring tool designed to track the uptime, latency, and service availability of multiple hosts simultaneously. This project demonstrates advanced networking concepts, system integration, and multi-threaded data management.

## Key Features
- **Live Status Dashboard:** Real-time terminal interface showing host health.
- **Latency Tracking:** Measures ICMP response times (ping) to monitor network lag.
- **Service Verification:** Actively checks critical ports (HTTP, HTTPS, SSH) to ensure services are responsive.
- **Cross-Platform:** Works on Windows, Linux, and macOS.

## Skills Showcased
- **Networking:** ICMP protocols, TCP Port Scanning, and Socket Programming.
- **Python Development:** OOP (Object Oriented Programming), System automation, and Time management.
- **DevOps:** Basic health checking logic used in professional NOC (Network Operations Center) environments.

## Installation & Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/aspirindev7-ops/NetGuardian.git
   ```
2. Run the monitor:
   ```bash
   python net_guardian.py
   ```
